# Direct fault lanes and interval traces

用户以截图明确要求：IMU 故障位直接替换状态分析右上角的状态字节图，不要子页；总览完整性区域直接绘制时间间隔、IMU 计数间隔。

- 状态分析恢复直接2×2：原始状态、故障位、温度、计数器；状态字节数值保留在左侧。
- Session 增加逐样本原始时间差(ms)及计数差值历史，随其它通道同步扩容/重置；首帧NaN，时间差取姿态回退前数值，计数差仅将−255转为+1。
- 完整性区域上下两张紧凑图，同步时间窗、游标和冻结快照，保留峰值/缺口、参考期望值与累计异常标题。
- 新增历史差值、回绕/倒退、绘图序列与右上角布局回归；先观察失败再实现。
- 不更改姿态算法、CSV列、DAT原始记录或硬件连接；正在运行的用户窗口不自动终止。

完成验证：53项测试通过；二进制/ASCII样例保持2000/797帧、CRC为0，既有1999帧真值比较三轴平均误差打印0.00000度；语法编译、diff whitespace检查通过。独立审查无重要发现。已查看默认及1100×720紧凑截图，确认右上故障位和总览两条间隔曲线直接可见。
