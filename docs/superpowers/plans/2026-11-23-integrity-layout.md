# Integrity / fault monitoring layout

用户要求数据完整性监控在监控总览、IMU 故障位在 IMU 状态分析；已确认完整性指标为 CRC、计数跳变和时间间隔异常。沿用直接实施与现有架构。

- [x] Session 记录原始间隔异常，再进行既有姿态 dt 回退；快照提供 CRC、计数跳变、重复计数、间隔异常、最新间隔及阈值。
- [x] 总览保留三组惯性曲线，第四格为数据完整性面板；按当前数据源累计，不将正常计数回绕当异常，不将跳变次数伪称丢帧数。
- [x] IMU 状态分析新增故障位/原始字段子页，默认显示完整八路故障时序，保持原始四图可用。
- [x] CRC-only 接收也可刷新统计，无需等待有效 IMU 帧；冻结快照包含完整性数据。
- [x] 回归测试先失败再实现通过；检查正常回绕、跳变/重复、回退前间隔、CRC-only统计及页面归属。
- [x] README、协议说明和两种窗口尺寸截图更新，独立审查与最终验证。

最终结果：51 项测试全部通过；二进制/ASCII 自检保持 2000/797 帧且 CRC 错误为0，原有真值比较三轴误差打印0.00000度。语法编译与diff whitespace检查通过。已查看1600×960、1100×720截图；独立审查无重要问题。未终止用户正在运行的窗口或连接硬件，代码更新在程序重启后生效。
