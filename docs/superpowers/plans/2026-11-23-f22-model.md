# F-22 model

用户要求模型使用 F22 战斗机。保留现有 Tk Canvas 三维渲染与 X前/Y右/Z下坐标、姿态算法和全部数据链路，直接替换 aircraft_parts() 返回的几何体。

简化外形包含尖机头、宽扁棱面机身、菱形机翼/平尾、外倾双垂尾、侧进气口、双矩形喷口和着色座舱；灰色涂装。不作为精确CAD或空气动力学模型。

新增双垂尾、网格有限值/索引/非退化面和极端姿态渲染回归，先观察旧模型单垂尾不满足要求，再实现通过。全部56项测试通过，语法编译和diff whitespace检查通过；已生成并查看默认/紧凑窗口截图。无需外部资产或新依赖，用户现有窗口不自动关闭，重启后使用新模型。
