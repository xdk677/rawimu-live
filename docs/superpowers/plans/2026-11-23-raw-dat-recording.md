# Raw DAT recording — implementation record

用户要求支持保存原始数据为 DAT；沿用前轮直接实施与现有 Python/Tkinter 架构。

- [x] Session.feed 在串口接收后、解析之前记录精确字节；不改变 CSV 列或回放解析格式。
- [x] 独立 raw_lock 保护打开/写入/关闭；捕获写入不完整、打开/关闭错误，DAT 错误不阻止解析。
- [x] SerialWorker 使用原始记录入口，并在正常断开、异常和打开失败时关闭原始文件。
- [x] 独立 DAT 按钮和文件菜单项，连接串口后可选择保存路径；与 CSV 可独立启停。保存对话框返回后，在同一锁下再次确认串口仍可接收，避免断开时遗留文件。
- [x] 切换数据源、退出时关闭文件，底部显示文件名/字节数/错误，诊断详情显示完整路径。
- [x] README 操作说明、原始字节/错误帧/未知数据验证、DAT/CSV 同录、断开刷新、对话框断开、窗口关闭回归。

测试先复现缺失行为，再实现验证；所有改动继续保留未提交。没有连接硬件或结束用户现有进程。

最终验证：44 项测试全部通过，两个既有样例自检保持原结果，语法编译与 diff whitespace 检查通过。独立审查发现退出时过早关闭 DAT 会漏掉正在读取的尾部字节；已增加阻塞读取回归，复现后将文件关闭延后至工作线程退出，审查者已复验确认修复。已检查最小窗口中的 DAT 按钮显示。
