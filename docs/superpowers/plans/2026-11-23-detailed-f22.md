# Detailed textured F-22

用户要求比原有低面数示意模型更真实的模型，沿用前轮直接实施偏好。

## Approach

使用 FlightGear / AeroFab 的实际 F-22 AC3D 模型与原始纹理（FGMEMBERS/F-22 固定提交，GPL-2.0）。原始资源、作者说明和完整许可保存在 assets/f22，模型与程序代码的许可分别说明。使用 pyopengltk/PyOpenGL 在 Tk 窗口内硬件加速显示，保留 Python3.7、现有数据/姿态/记录功能；无可用OpenGL时保留兼容模型并展示诊断。当前机器依赖安装在项目私有.vendor，不更改系统Python包。

## Tasks

- [x] AC3D解析与模型准备：层级变换、UV、平滑法线、外观部件、坐标映射到X前/Y右/Z下、尺寸归一化与资源缓存。
- [x] OpenGL视图：深度测试、纹理、光照、高光、地台/罗盘/轴/影子、姿态驱动；正确清理GPU资源，渲染失败回退。
- [x] 集成与打包配置：保留原Canvas接口，截图读回GPU画面并合成；新增依赖/资产打包，来源与许可说明。
- [x] 验证：解析夹具、模型数组/坐标、真实OpenGL渲染及截图、原有全部测试/样例自检、帧耗时与效果图、独立审查。

## Validation

全部63项 unittest 通过；二进制2000帧/真值1999帧、ASCII797帧自检通过；py_compile 和 git diff --check 通过。真实 Intel UHD Graphics730 / OpenGL4.6 渲染、窗口缩放、截图合成、失败回退和清理失败注入已验证。网格共28846个三角面；960x720视图20帧CPU绘制命令平均约4.54ms（不代表完整界面耗时）。默认及紧凑布局截图已查看，模型细节图保存在 docs/images/f22_detailed.png。独立审查发现大姿态地台遮挡，已通过独立深度通道修复；投影采用stencil每像素混合一次以消除重叠噪点。最终审查无重要未解决问题。更新了exe打包配置，未构建或运行exe产物。

## Constraints

不终止用户现有窗口、不连接串口硬件。起落架/内部调试物体隐藏以显示飞行外观。使用模型源资产，不宣称它是制造级CAD。测试既覆盖兼容Canvas，也单独覆盖实际OpenGL。保留可复现来源提交和未修改原始文件；GPL资产随包附源与许可，不将其标为MIT。
