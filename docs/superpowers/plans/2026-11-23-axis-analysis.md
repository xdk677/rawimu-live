# IMU independent axis analysis implementation plan

**Goal:** 按用户参考图新增独立3×3分析窗口，首行时间间隔/温度/周计数，第二行X/Y/Z角速度，第三行X/Y/Z加速度。

**Architecture:** 复用现有PlotPanel和Session快照。窗口放在src/axis_analysis.py，由App同一刷新循环驱动；关闭窗口不改变数据源。沿用Python3.7/Tkinter，无新增依赖。此前用户选择直接实施，本次布局以新截图为准。

**Display:** 时间间隔采用ms，周计数为报文week字段，区别于8位IMU采样计数。角速度沿用主窗口去零偏值，加速度沿用主窗口物理量。各图独立纵轴，统一时间窗/冻结/游标；六轴叠加尾随5秒均值。均值统计原始可见样本，PP统计可见滑动平均，初期不足5秒按已有样本计算；NaN和时间回退重置均值。无数据明确占位。
