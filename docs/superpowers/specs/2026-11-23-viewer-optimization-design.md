# RAWIMU Live 性能、稳定性与显示优化设计

状态：2026-11-23 用户选择“按这个方案直接实施”，沿用 Python/Tkinter 并跳过后续设计讨论。

## 目标与约束

- 修复回放速度、停止/关闭的线程竞争，减少 CRC 和绘图开销，让大文件自检使用有界内存。
- 让操作者立即识别数据来源、连接状态、姿态、标定和记录状态；在窗口缩放时仍能操作。
- 保留 Python/Tkinter、现有 CLI、JSON 协议/型号扩展、CSV 列及 Windows 打包方式。
- 环境实际为 Python 3.7.0、Tk 8.6、pyserial 3.5；实现不得使用更新 Python 才支持的语法或 API。
- 本轮范围为 Python 工具及相关文档、验证，不同步重写 MATLAB，不改变姿态融合算法和量纲。

## 方案比较

1. 推荐：在现有 Tkinter 中调整布局，明确数据状态，优化后台生命周期与绘制。依赖和打包变化最小，可复用全部解析和三维场景代码。
2. 迁移 Qt：可获得更丰富控件，但增加依赖、打包体积和迁移验证成本，目前需求没有必须迁移的限制。

用户选择直接实施，采用方案 1，具体视觉细节交由实现者决定。

## 已知证据

- 二进制样例 2000 帧，三轴姿态真值平均绝对误差均打印为 0.00000 度；ASCII 样例 797 个 IMU 帧，均无 CRC 错误。
- 两组数据按 1、7、8192 字节分块均获得相同帧数，无残留字节。
- 使用模拟时钟执行 1 倍速回放，19.99 秒数据只累计等待 4.50 秒。根因是每批仅 sleep(min(lag, 0.25)) 一次。
- 记录关闭和写入缺少共同锁；snapshot 返回可被后台修改的 Attitude 实例；姿态更新和 UI 重置未使用共同锁。
- 自检一次性 read 整个文件，且仅保留最后 6000 点，长文件真值比较会与开头真值错位。
- 68 字节 CRC 调用 20000 次，当前 Python 实现约 0.1525 秒，候选原生计算约 0.0033 秒；这只是 CRC 微基准，并非全程序加速比例。

## 后台与数据处理

- CRC 使用标准库 zlib，通过初值与最终异或适配设备的初值 0、末尾不取反约定。用旧参考算法、随机/边界输入及样例验证精确一致。
- 工作者使用独立的停止事件，停止请求在串口打开或文件打开期间也不能丢失。串口、文件句柄在 finally 中关闭。
- 回放使用 monotonic 时间，每批按数据时间计算目标时刻；可中断等待直到目标，不再只等一次固定上限。0 倍速表示不节流，负数/非有限速度拒绝。批量解析会保留小幅突发，不宣称逐帧精确调度。
- 连接和回放互斥；线程完全退出前不能启动新数据源。UI 采用 after 检查退出，避免长时间 join 卡住主线程。
- Session 的姿态积分、重置/标定和快照遵守同一锁约定，快照复制姿态和标定显示需要的值，避免共享可变对象。
- CSV 的开启、写入、关闭使用共同同步机制；写入失败关闭记录并展示独立记录错误，避免结束串口解析。保持现有列顺序，Windows 使用 newline='' 防止空行。
- 自检分块读文件，流式对齐真值，累计误差而不保留全文件；维持当前样例真值相差一行的既有约定并验证。空数据、缺少匹配数据给出明确失败结果，真值比较不除以零；发现结构不匹配应报告，不能静默宣称通过。

## 界面与显示

- 顶部两排分组：数据源（端口、刷新端口、波特率、连接/断开、打开回放）；算法（IMU、融合模式、重力时间常数、归零、重新标定、记录）。
- 主区左侧：三张显著角度读数（横滚 Roll、俯仰 Pitch、航向 Yaw），下方保留飞机、罗盘、轴方向与地面投影。增加标准视角恢复，具体交互由实现者选择。
- 主区右侧：姿态角、角速度、加速度按纵向排列，每张图有短标题、单位、独立颜色图例和当前值，避免长标题遮挡。
- 颜色规则保持 X/Roll 红、Y/Pitch 绿、Z/Yaw 蓝，重力参考使用对应颜色虚线；文字标明实线为当前解算输出，互补模式下不误称纯陀螺积分。
- 底部持续状态区：未连接/连接中/等待数据/接收中/已断开/回放中/回放结束/错误；显示采样率、温度、帧数、CRC 错误、零偏标定进度、记录路径。状态使用文字和颜色双重编码，错误不能被常规刷新覆盖。
- 无数据时三维场景、图例、坐标区和占位读数仍然可见，未采样角度显示“—”，不伪装成测得的 0 度。
- 回放支持文件选择、明确速度及结束状态；暂停、拖动时间轴、CSV 回放不属于本轮范围。
- 默认窗口约 1480×900，目标支持 1100×720；不适合主区的信息放入可折叠详情或独立详情区域，避免固定 Canvas 文本截断。
- 按窗口像素宽度对显示数据分桶，保留时间顺序下的首尾/极值，不改变解算和记录数据。NaN 参考间隙保持断线，不跨间隙连线；姿态穿越 ±180 度时避免绘出误导性竖线。
- 缓存可复用的图形对象；没有数据更新且没有尺寸/显示设置变化时跳过昂贵重绘。视窗时间可选 10/30/60 秒，保留缓冲必须足以覆盖声明支持的时间。
